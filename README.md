# Каталог плитки «Алмалы-Керамик» + QR-коды

Статический сайт-каталог по рабочим артикулам из Google-таблицы. У каждой модели
своя страница с галереей и свой QR-код с названием и артикулом в центре.

## Редактор медиа онлайн (с любого устройства)

https://almaliceramicc.github.io/almaly-tiles/admin.html — вход по GitHub-токену
(fine-grained, репозиторий `almaly-tiles`, Repository permissions → Contents: Read and write).
Токен сохраняется в браузере. Загрузка, удаление, порядок и обложка пишутся коммитом в `photos/`,
после чего GitHub Action пересобирает сайт и QR-коды (1–2 минуты). Фото при загрузке
автоматически ужимаются до 1600 px.

Каталог сам обновляется из Google-таблицы каждую ночь (workflow «Пересборка каталога»,
он же запускается кнопкой Run workflow вручную).

## Редактор медиа на Mac

   ./edit.sh

Откроется http://localhost:8787 — список всех моделей: перетаскивание файлов,
удаление, стрелки для порядка, ★ — сделать обложкой, кнопка «Опубликовать изменения»
пересобирает сайт и выкладывает его. Файлы правятся прямо в `photos/<АРТИКУЛ>/`.

## Как добавить фото вручную

1. Положить файлы в `photos/<АРТИКУЛ>/` (папки уже созданы для всех рабочих артикулов).
   Порядок — по имени файла: `01.jpg`, `02.jpg`, ... Первое фото становится обложкой.
2. Собрать сайт:

   python3 build.py

3. Выложить обновление (если сайт уже на GitHub Pages):

   ./publish.sh

## Как обновить список плиток из таблицы

   python3 sync_sheet.py && python3 build.py

## Что где

- `data/*.csv` — выгрузка листов таблицы (60×60 и 60×120)
- `photos/<АРТИКУЛ>/` — исходные фото (полный размер, в сайт не попадают)
- `docs/` — готовый сайт: `index.html` (каталог), `tile.html?a=АРТИКУЛ`, `print.html` (лист QR на печать)
- `editor.py` + `editor.html` — редактор медиа (`./edit.sh`)
- `qr/<АРТИКУЛ>.png` — QR-коды 1000×1000 для печати и наклеек
- `config.json` — адрес сайта. QR-коды строятся из него: поменял адрес — перезапусти `build.py`

Остатки складов на сайт намеренно не выводятся.
